# Benchmark Task: Architecture Explanation

## Task

Explain the overall architecture of this repository, including all major components and how they relate to each other.

## Expected Coverage

Your answer should include:
1. Whether this is a monorepo or single project
2. All major packages/modules and their purposes
3. The primary programming languages used
4. How the components relate to and depend on each other
5. The general architectural pattern (MVC, microservices, etc.)

## Scoring Rubric

| Score | Criteria |
|-------|----------|
| 5 | Identifies all major components, correct relationships, no hallucinations |
| 4 | Identifies most components, minor gaps in relationships |
| 3 | Identifies main components but misses some, some relationship errors |
| 2 | Partial identification, significant gaps or errors |
| 1 | Mostly incorrect or very incomplete |
